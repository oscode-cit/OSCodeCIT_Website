# OSCode CIT Website

Official website for **OSCode CIT — Open Source Community, Cambridge Institute of Technology, Bengaluru**.

The website serves as the digital presence of OSCode CIT, showcasing the community, team members, events, activities, and ways to connect with the community.

---

## 🌐 About OSCode CIT

OSCode CIT is an open-source community at **Cambridge Institute of Technology, Bengaluru**, focused on helping students learn, collaborate, build projects, and participate in the open-source ecosystem.

The community aims to create an environment where students can:

- Learn modern development technologies
- Contribute to open-source projects
- Participate in workshops and hackathons
- Collaborate with fellow developers
- Explore emerging technologies
- Build real-world projects
- Network with other developers
- Grow through community and innovation

---

## 🚀 Getting Started

### 📋 Prerequisites

Make sure the following are installed on your system:

- **Node.js** v18 or higher
- **npm** or **yarn**
- **Git**

### Installation

1. Clone the repository:
```bash
git clone https://github.com/oscode-cit/OSCodeCIT_Website.git
cd OSCodeCIT_Website
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`
